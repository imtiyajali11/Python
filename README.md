# Python Practice

## Contents

This repository includes notebooks for:

- Variables and data types
- Control flow
- Loops
- Functions
- Lists
- Tuples
- Sets
- Dictionaries
- Practice problems
- Small beginner projects

## Purpose

This repository is for learning and practicing Python through hands-on notebook exercises.

## Files

Each notebook focuses on a specific topic or exercise, such as:

- `loops.ipynb`
- `functions.ipynb`
- `list index.ipynb`
- `TupleQuestions.ipynb`
- `DictionaryQuestions.ipynb`
- `calculator.ipynb`

## How to Use

1. Open any notebook in Jupyter Notebook or VS Code.
2. Run the cells one by one.
3. Modify the examples and try your own inputs.
